## Déploiement en 1 clic

### Option 1 : Streamlit Cloud (Gratuit, recommandé)
1. Fork ce repo
2. Va sur https://share.streamlit.io
3. New app -> Sélectionne ce repo -> main file: `app.py`
4. Deploy !

### Option 2 : GitHub Codespaces (Sans install)
1. Sur ce repo, clique `Code` > `Codespaces` > `Create codespace`
2. Attends 30s puis tape dans le terminal:
```
streamlit run app.py --server.port 8501
```
